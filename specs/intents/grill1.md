# grill-me-docs-1

This is my first grill-me-docs session, i expect plenty will occurs.

My primary objectif is to be able to setup a simple `nixos` configuration using git with `comin` so i can start to iterate on it.  Eventually, i will be supporting several computer and configuration, some sharing common setup other being very different.

The goal is to create a DRY (don't repeat yourself) approach where all configuration is well organized and easy to understand.
